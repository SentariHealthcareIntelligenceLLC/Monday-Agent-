One unattended loop, every day

Vercel Cron fires hourly; each job runs only when the local clinic hour matches — DST-proof by design. Weekly, monthly, quarterly and yearly duties roll into the same morning message on the day they fall due, with lead_days opening the window early for big items like accreditation packets.

One codebase, two deployment shapes

Set DATABASE_URL → Vercel + Supabase Postgres with Vercel Cron. Leave it empty → a single Docker/VPS process on SQLite. One npm dependency (pg), no build step.

Meta WhatsApp Cloud API

  • Template morning lists, plain-text nudges
  • Signed webhook (X-Hub-Signature-256)
  • Retries deduplicated by message id

Vercel

  • Serverless entrypoint + hourly cron, local-hour matched
  • Dashboard: board, team, planners, scheduling, time clock, messages, rules
  • Region pinned next to the database

Supabase Postgres

  • 16 core tables, security-invoker views, RLS everywhere
  • NEW Supabase Auth: profiles, role-based policies (owner / manager / staff / viewer)
  • NEW WhatsApp connections: sender accounts (secrets in Vault), per-person opt-in, 24-hour session window, webhook event log, delivery receipts
  • Private Storage bucket for photo proof, signed URLs
PHI boundary: WhatsApp Cloud API is not HIPAA-eligible and Meta signs no BAA — task names stay generic ("Verify insurance for tomorrow's list"), patients are referred to by internal ID only, and photo proof lives in a private bucket, never in the chat.
